# Знакомство с библиотекой PyTorch

Вводный урок по библиотеке PyTorch перед изучением нейронных сетей.

1. `pytorch_basics.ipynb` - разбор основных операций PyTorch:
   * тензоры и их атрибуты;
   * типы данных;
   * арифметические и матричные операции;
   * агрегация, индексация, изменение формы, соединение тензоров;
   * совместимость с NumPy;
   * работа с устройствами (CPU/GPU);
   * автоматическое дифференцирование (Autograd);
   * загрузка данных: встроенные наборы данных torchvision (Fashion-MNIST), классы `Dataset` и `DataLoader`, чтение изображений из папки.
2. `images` - примеры изображений для знакомства с загрузчиком данных.
